System Monitor Dashboard

A web-based system monitoring dashboard built with Python, Flask, and psutil.

Features

- Monitor CPU usage
- Monitor memory usage
- Monitor disk usage
- Display usage with progress bars
- Show alerts for high resource usage
- Automatically refresh the dashboard every 5 seconds
- Display the last updated time
- Change progress bar colors based on resource usage

Technologies Used

- Python
- Flask
- psutil
- HTML
- CSS
- Git and GitHub

Installation

1. Clone this repository:
   
   git clone https://github.com/Abhishek2007-shell/system-monitor-web.git

2. Open the project directory:
   
   cd system-monitor-web

3. Install the dependencies:
   
   pip install flask psutil

4. Run the application:
   
   python app.py

5. Open your browser and visit:
   
   "http://127.0.0.1:5000"

Purpose

This project demonstrates basic system monitoring, Python web development, and dashboard creation skills relevant to cloud computing and DevOps.
